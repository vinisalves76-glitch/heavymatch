# HeavyMatch

Marketplace digital com experiência mobile de descoberta de caminhões, carretas e máquinas pesadas.

## Estado atual
- Protótipo HTML/CSS/JavaScript em evolução.
- Catálogo demonstrativo; anúncios reais ainda precisam ser cadastrados.
- O número de WhatsApp no código é um placeholder e deve ser configurado antes de uso comercial.
- Favoritos são mantidos apenas durante a sessão do navegador; persistência/banco de dados ainda não foi integrado.

## Desenvolvimento
As funcionalidades novas devem ser trabalhadas primeiro em branches de desenvolvimento e testadas em uma preview antes de qualquer publicação em produção.
