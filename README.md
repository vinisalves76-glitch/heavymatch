# HeavyMatch

Marketplace digital com experiência mobile de descoberta de caminhões, carretas e máquinas pesadas.

## Ambiente de desenvolvimento
- Branch de trabalho: `feature/mobile-first-marketplace`
- Aplicação inicial: `index.html` com HTML, CSS e JavaScript.
- A branch `main` é a referência de produção; não mesclar sem aprovação explícita.
- Use a preview do Vercel para validar alterações antes de abrir/mesclar um PR.

## Estado atual do protótipo
- Catálogo demonstrativo com seis anúncios.
- Favoritos funcionam apenas durante a sessão atual do navegador.
- Não há banco de dados, login, painel administrativo ou sincronização com vendedores.
- O WhatsApp do consultor está como placeholder no JavaScript (`WHATSAPP_NUMBER`); configure o número real antes de uso comercial.
- As imagens do catálogo são referências de demonstração; devem ser trocadas por fotos reais e autorizadas dos anúncios.

## Fluxo de trabalho
1. Desenvolver em uma branch de funcionalidade.
2. Conferir a preview e testar no celular/desktop.
3. Corrigir os problemas encontrados.
4. Só mesclar em `main` depois da aprovação explícita do responsável.
